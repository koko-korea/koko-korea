## 1. 개요

### 1.1 목적
중학교 2학년 학생이 3단원 문법(음운 체계, 훈민정음)을 **게임처럼 재미있게** 복습하게 한다. 학생은 틀린 문제를 해설과 **동형 문제**로 바로 다시 익히고, 교사는 수업 중에 반 전체의 이해도와 **상위 3명 순위**를 확인한다.

### 1.2 핵심 원칙
| 원칙 | 내용 |
|---|---|
| 간편 로그인 | 학번(4자리) + 이름 + 캐릭터(남/여)만 입력, 비밀번호 없음 |
| 데이터 미저장 | 서버·DB·localStorage에 학생 정보를 저장하지 않음. 모든 기록은 브라우저 메모리에만 있고 창을 닫으면 사라짐 |
| 한 번의 기회 | 같은 학번은 한 수업에서 한 번만 응시 |
| 저작권 안전 | 게임 원작의 캐릭터·로고·아이콘을 쓰지 않음. 분위기(색감·나무 질감·둥근 UI)만 참고해 직접 만든 그래픽 사용 |
| 친숙함·성취감 | 3D 학교 광장, 귀여운 국어쌤 캐릭터, 칭찬·응원 리액션, 축하 연출 |

### 1.3 사용자
- **학생**: 중학교 2학년. 크롬북·노트북·태블릿·휴대폰 등 여러 기기를 섞어 사용
- **교사**: 국어 교사. 전자칠판/교사 PC로 교사 화면을 띄움
- 학번 형식: `2101` = 2학년 1반 1번 (현재 2학년은 1개 반)

## 3. 문제 은행

### 3.1 구성 (현재 50문항 + 동형 50문항)
| 영역 | 5지 선다형 | 단답형 |
|---|---|---|
| 음운 | 5 | 2 |
| 모음 체계 | 7 | 3 |
| 자음 체계 | 8 | 3 |
| 창제 정신 | 3 | 2 |
| 창제 원리 | 8 | 5 |
| 말소리와 문자 | 3 | 1 |
| **합계** | **34** | **16** |

모든 원래 문제에는 **동형 문제가 1개씩** 짝지어져 있다 (같은 개념, 다른 예시·물음).

### 3.2 데이터 형식
```js
// 원래 문제
{ cat: "자음 체계", type: "mc",            // "mc"=5지 선다, "sa"=단답형
  q: "비음(콧소리)으로만 묶인 것은?",
  o: ["ㅁ, ㄴ, ㅇ", "ㅁ, ㄴ, ㄹ", ...],     // mc만, 보기 5개
  a: 0,                                    // mc: 정답 보기 번호(0부터) / sa: 인정 답 배열 ["비음","콧소리"] — 인정할 표현을 모두 적음
  e: "비음은 입안의 통로를 막고 …",          // 해설
  tbl: [["","양순음","치조음"],[...]],      // 선택: 문제에 붙는 표
  concept: "비음",                          // 정답 칭찬 대사용 핵심 개념
  t: { /* 동형 문제: 같은 구조 */ } }
```

### 3.3 출제 규칙
- 교사가 정한 수만큼 **5지 선다형 N개 + 단답형 M개**를 무작위로 뽑는다 (기본 10 + 5)
- 5지 선다형은 보기 순서도 매번 섞는다
- 단답형 채점 (v1.1)
  - 정답 판정은 **문항마다 적어 둔 인정 답 배열(`a`)과 일치하는지**로만 한다. 정규화로 답을 추측하지 않는다. (예: “가획”과 “가획의 원리”를 모두 인정하려면 두 표현을 모두 `a`에 적는다)
  - 비교 전 정규화(입력과 인정 답 모두): 유니코드 NFC, 모든 공백 제거, 따옴표·마침표·쉼표·물음표·느낌표·괄호 제거, 끝의 ‘이다/입니다/이에요/예요’ 제거
  - 옛한글(ㆍ, ㅿ, ㆆ, ㆁ 등)이 정답인 문항은 크롬북·휴대폰에서 입력하기 어려우므로 **5지 선다형으로 내거나, 이름(예: “아래아”, “반치음”)도 인정 답에 넣는다**

### 3.4 남은 과제
- [ ] 교사의 원래 문제 50개, 동형 문제 50개 검토 (교사가 "나중에 검토"로 정함)
- [ ] 검토용으로 문제를 표(CSV/스프레드시트)로 내보내고 다시 불러오는 기능 고려

## 4. 점수·시간·순위 규칙

| 항목 | 규칙 |
|---|---|
| 제한 시간 | 문제당 **1분**. 화면 위 가운데에 `00:59` 형식으로 카운트다운, 10초 이하에서 빨갛게 깜빡임, 5초부터 째깍 소리 |
| 정답 | 한 번에 맞히면 **1점** |
| 오답·시간 초과 | 해설을 먼저 보여 준 뒤 **동형 문제 1회** 제공 (동형 문제도 1분) |
| 동형 문제 정답 | **0.5점** |
| 동형 문제 오답 | 0점 |
| 순위 | 점수 높은 순 → 같으면 **전체 풀이 시간 짧은 순** |
| 풀이 시간 (v1.1) | 각 문제(동형 문제 포함)가 **화면에 나온 순간부터 제출 또는 시간 초과까지** 걸린 시간의 합. 해설·칭찬 대사를 읽는 시간과 시작/종료 띠 팝업 시간은 넣지 않음. 문제 하나당 최대 60초 |
| 응시 기회 | 같은 학번은 1회만. 교사 쪽에서 **접속(join) 순간 학번을 잠금** (v1.1, 8.1 참고) |
| 오답 연습 | 결과 화면에서 "틀린 문제만 다시 풀기" 가능. 시간 제한 없음, **점수·순위 미반영** |

### 화면 1. 시작 화면
- **3D 학교 광장** (WebGL): 보랏빛 박공지붕·시계탑·흰 기둥·나무 겹문이 있는 ‘문법의 숲 중학교’, 물방울이 튀는 2단 분수, 벤치, 그루터기 의자와 둥근 탁자, 가로등, 둥근 나무·침엽수·산울타리, 꽃밭, 풍선 다발, 가로등 사이 가랜드
- **교복 입은 학생 인형 10명** (남·여): 검정 재킷, 흰 셔츠 깃, 초록·노랑 줄무늬 넥타이, 남학생 회색 바지 / 여학생 회색 주름치마, 책가방. 분수 주변을 돌거나 걷고, 벤치에 앉거나 제자리에서 뜀
- 카메라가 천천히 좌우로 흔들림
- **시간대별 하늘**(접속 시각 기준): 아침 / 낮(무지개) / 저녁(노을) / 밤(별, 창문·가로등 불빛)
- 날리는 나뭇잎, 나비
- **제목**: 나무판 없이 글자만, 시계탑 쪽 위치. 위에 “놀러 와요,”, 가운데 `문` `법` `의` `숲` 한 글자씩 **색깔이 다른 나뭇잎 모양 블록**(흰 글자, 갈색 테두리, 살랑 흔들림), 아래 “음운과 훈민정음 퀴즈”
- **오른쪽 국어쌤**: 손을 번쩍 들고 기뻐하는 몸동작, 웃는 표정, 흰 구름 말풍선(20pt) “같이 공부해요! :D”
- **입장 버튼**: 기둥 두 개 달린 나무 팻말 “🌳 문법의 숲 입장”, 숨 쉬듯 커졌다 작아짐. 화면 아무 곳이나 눌러도 입장, Enter/Space 지원
- 3D가 안 되는 기기에서는 2D 산·폭포·피크닉 배경으로 대체

### 화면 2. 로그인 (대화창 형식)
- 배경: 3D 광장을 흐리게 깔고 그 위에 대화 장면
- 국어쌤 대사: “어서 와요! 문법의 숲에 온 걸 환영해요. 학번, 이름, 캐릭터를 골라 줄래요? :D”
- 입력칸은 **나무 이름표** 모양 (못 장식, 흰 글자 라벨)

  - 🎒 학번 4자리: 입력 즉시 “2학년 1반 1번”으로 풀어 보여 줌, 형식 오류·이미 응시한 학번 안내
  - 🏷️ 이름: 한글 2~5자
  - 🧑‍🎓 캐릭터: 👦 남학생 / 👧 여학생 (순위 발표·결과 화면 캐릭터에 사용)

- 안내문: “학번·이름과 점수는 어디에도 저장되지 않아요. 문제 풀이 기회는 한 번이에요.”

### 화면 3. 문제 풀이·해설
- 위쪽: 가운데에 **시계 알약(남은 시간)**과 **잎사귀 알약(푼 문제 수 / 전체)**, 그 아래 **잎사귀 도장 띠**(문제마다 잎 하나: 현재 주황 테두리로 콩닥, 정답 초록 ✓, 동형으로 맞힘 반쪽 노랑, 틀림 회색)
- 오른쪽 위: 학번·이름 칩, ⭐ 점수 칩, 🔊 소리 켜기/끄기
- 국어쌤·대사창·선택지를 **큰 나무판 하나**가 감쌈
  - 왼쪽: 국어쌤 + 대사창 (이름표 “문제 n / 15”, 영역 태그, 문제 유형). 대사창이 국어쌤 몸을 살짝 덮되 **얼굴과 카라는 보이게**
  - 오른쪽: 선택지 판. 보기 번호는 **연두색 잎사귀**로 통일, 고르면 노랗게
  - **제출 버튼**: 분홍 꽃잎 6장 + 큰 노란 꽃술의 **꽃 모양**, 지름 약 100px, 글자 “제출” 진하게. 보기를 고르면 살랑살랑 흔들림
  - 단답형은 입력칸 + 꽃 제출 버튼 (Enter 지원)
- 국어쌤 대사 전: 머리 위 생각 구름 “● ● ●”, 이어서 타자 치듯 대사 출력 (말할 때 입이 움직임)
- **글자 크기**: 문제 17pt, 해설 14pt, 보기 14pt. 글꼴은 함초롬돋움처럼 각진 고딕(나눔고딕 굵게, 함초롬돋움이 설치돼 있으면 그것을 먼저 사용)
- **정답 반응**: 국어쌤이 만세·박수·손 흔들기 중 하나를 하며 다문 입으로 미소, “대단해! / 최고야!” 말풍선 팝 + 반짝이, 대사 “딩동댕! ‘원순 모음’을 배웠어요! 정말 대단해요~ :D” + 해설
- **오답 반응**: 국어쌤이 동그란 큰 눈·올라간 눈썹·벌린 입으로 **깜짝 놀라고**, 뒤에 **노란 번쩍 표시**와 “헉!” 말풍선 → 1초 뒤 주먹을 불끈 쥐며 “힘내!/할 수 있어!” 응원. 대사 “괜찮아요! 이번에 제대로 배우면 돼요. 정답은 ○○이에요. :)” + 해설
- 대사창을 누르거나 Enter로 다음 진행 (▼ 깜빡임)

### 화면 4. 동형 문제 카드 (교사 만족 — 디자인 유지)
- 민트색 잎 무늬 배경 위 노란 카드, 크림색 잎 무늬 안쪽
- 왼쪽 위 빨간 “동형 문제” 딱지, 오른쪽 위 “⭐ 맞히면 +0.5점”
- 제목 “한 번 더 도전해 봐요!”, 국어쌤 한마디 “… 맞히면 0.5점을 받을 수 있어요! :)”
- 보기 번호 연두 잎사귀, 꽃 모양 **제출** 버튼, 원형 1분 타이머, 잎사귀 도장 줄
- 결과: 금색 리본 “⭐ 0.5점 GET!” 또는 회색 리본 “아쉬워요” + 정답·해설 → 나무 팻말 “🌳 계속하기”

### 화면 5. 결과 (학생은 이 화면에서 대기)
- 국어쌤 대사: “○○ 학생, 끝까지 잘 해냈어요! 오늘 점수는 ○점 (15점 만점)이에요. :D / 순위는 선생님 화면에서 함께 발표할게요.”
- 국어쌤 옆에 **로그인 때 고른 내 캐릭터(교복 남/여)**가 “해냈다! 🎉” 하며 기뻐함
- **오늘의 점수**: 노란 별판 위 큰 숫자가 0부터 올라가고 다 오르면 색종이 + 효과음
- 나의 도장 카드(잎사귀), 한 번에 맞힘 / 동형으로 맞힘 / 걸린 시간
- “✏️ 틀린 문제만 다시 풀기 (점수 미반영)”, “내 답 다시 보기”(내 답·정답·해설·동형 문제 기록)
- **‘다음 학생’ 버튼 없음** (각자 기기 사용)

### 화면 6. 교사 화면
- 진입: 로그인 화면의 “교사용 화면” → **비밀번호(숫자 4자리)를 수업마다 새로 정함**(처음 들어갈 때 정하고, 이후 그 비밀번호로 입장. 메모리에만 보관)
- 나무판 패널, 제목은 흰 글씨 + 갈색 테두리
- ⚙️ **문항 수 설정**: 5지 선다형 / 단답형 각각 **−/+ 버튼** (최대 34 / 16). 바꾸면 접속한 학생 기기에 즉시 전달
- 📡 **실시간 방**: “방 열기” → 6자리 방 코드 + **QR 코드**(링크에 `#room-123456`) + 링크 복사 + “수업 종료(방 닫고 기록 지우기)”
- 👀 **참여 현황**: 접속 n명 · 완료 n명, 학번순 목록 (푸는 중 ✏️ / 점수·시간)
- 📉 **많이 틀린 문제**: 정답률 낮은 5문항을 **막대그래프**(40% 미만 주황, 70% 미만 노랑, 그 이상 초록)로
- 🏆 순위 발표, 순위 초기화(두 번 눌러 확인), 학생 화면으로
- 결과 글씨는 진하게 (나눔고딕 800)

### 화면 7. 순위 발표 — 오늘의 문법왕
- 남색 밤하늘 배경, 위쪽 색 삼각 깃발 가랜드와 흔들리는 노란 별, 양옆 풍선
- **양쪽에서 폭죽이 터짐**(캔버스), 떠다니는 음표 ♪♫♬♩, 쏟아지는 색종이, 작은 축하 소리(파티 호른·폭죽음·팡파르)
- **교실 장면**: 초록 칠판(“🎉 오늘의 문법왕 🎉”, 참여 n명, ㄱ ㄴ ㅁ ㅅ ㅇ · ㆍ ㅡ ㅣ 분필 낙서), 나무 바닥
- 칠판 앞에 **1~3위 학생 캐릭터(교복, 학생이 고른 남/여)**가 웃으며 서 있음: 1위 가운데·가장 크게·**왕관**·손 들고 기뻐함 / 2위 손 흔들기 / 3위 팔 흔들며 응원

- 3위 → 2위 → 1위 순서로 등장하며 효과음
- 오른쪽에서 국어쌤이 박수: “축하해요! 짝짝짝 :D”
- ‘참 잘했어요’ 도장은 **넣지 않음** (교사 결정)

## 8. 실시간 연결 (학생 각자 기기 → 교사 화면)

### 8.1 방식 (현재 시제품)
- **PeerJS**(WebRTC)로 교사 브라우저와 학생 브라우저를 **직접 연결**. 방 코드 6자리 → peer id `munbeop-forest-2026-<코드>`
- 공개 PeerJS 신호 서버는 **연결을 맺을 때만** 쓰고, 점수는 교사 브라우저 메모리에만 모인다 (서버 저장 없음)
- 메시지
  - 교사 → 학생: `{type:"config", mc, sa}`, `{type:"reject", reason}`, `{type:"closed"}`
  - 학생 → 교사: `{type:"join", sid, name, sex}`, `{type:"done", sid, name, sex, score, sec, stats:[[bankIndex, okFirstTry], …]}`
- 교사 쪽 검증: 학번 형식, **이미 접속한 학번 거부**(v1.1, 완료 여부와 무관), 점수 범위 제한
- 학번 잠금과 재입장 (v1.1)
  - 학생이 `join`을 보내는 순간 교사 쪽에 그 학번이 잠긴다. 같은 학번으로 다시 `join`하면 `{type:"reject", reason:"already-joined"}`
  - 새로고침·연결 끊김 등으로 학생이 다시 들어와야 하면, 교사가 참여 현황 목록의 **‘재입장 허용’** 버튼으로 잠금을 푼다. 이때 그 학생의 기록은 지워지고 처음부터 다시 푼다
  - 학생 화면은 퀴즈를 푸는 중에 `beforeunload` 경고를 띄운다(“지금 나가면 선생님이 허용해야 다시 들어올 수 있어요”)
  - 교사 화면은 방이 열려 있는 동안 `beforeunload` 경고를 띄운다(“닫으면 모든 학생 기록이 사라져요”)
- 방 코드를 비우면 **단독 모드**(한 기기 안에서만 기록, 전자칠판 한 대로 돌아가며 풀 때)

### 8.2 개발 시 확인·결정할 점
- [ ] **학교 와이파이에서 WebRTC/PeerJS 연결이 되는지** 기기 2대로 사전 점검 (이 시제품은 외부 네트워크가 막힌 환경에서 만들어 실제 연결 시험은 하지 못함)
- [ ] 막히면 대안: Firebase Realtime Database(수업 중 임시 저장 → ‘수업 종료’ 때 삭제) 또는 학교 내부 WebSocket 서버
- [x] 학생이 도중에 새로고침하면 다시 응시할 수 있는 문제 → v1.1: 접속 순간 학번 잠금 + 교사 ‘재입장 허용’
- [ ] 학생 화면에 “방 연결 끊김” 표시와 재연결

### 8.3 배포
- 정적 파일 하나(`index.html`)로 배포: Netlify Drop, GitHub Pages, 학교 홈페이지 등
- 외부 리소스: Google Fonts(Jua, Gowun Dodum, Nanum Gothic), unpkg PeerJS, cdnjs qrcodejs. 오프라인일 때도 퀴즈 자체는 동작해야 함(글꼴은 기본 글꼴로 대체, 실시간·QR만 비활성)

## 11. 수용 기준 (Acceptance Criteria)

1. 학번 4자리·이름·캐릭터를 모두 입력해야 시작할 수 있고, 같은 학번은 두 번 응시할 수 없다. 이미 접속한 학번은 교사가 ‘재입장 허용’을 누르기 전까지 다시 들어올 수 없다.
2. 교사가 정한 수(선다형 N + 단답형 M)만큼 무작위로 출제되고 보기 순서가 섞인다.
3. 문제마다 1분이 지나면 자동으로 오답 처리되고 해설 → 동형 문제로 넘어간다.
4. 점수는 한 번에 정답 1점, 동형 정답 0.5점으로 계산되고, 순위는 점수 → 풀이 시간(4절 정의, 해설 읽는 시간 제외) 순이다.
5. 국어쌤 대사 끝에는 항상 :D 또는 :)가 붙는다.
6. 정답이면 칭찬 리액션과 “‘개념’을 배웠어요! 대단해요” 대사, 오답이면 놀람 → 응원 리액션이 나온다.
7. 교사 화면은 비밀번호로만 들어갈 수 있고, 문항 수·참여 현황·많이 틀린 문제·순위 발표가 동작한다.
8. 순위 발표에서 1~3위 학생 캐릭터가 교실 앞에 고른 성별대로 나오고, 1위에 왕관, 폭죽·음표·축하 소리가 나온다.
9. 새로고침하거나 ‘수업 종료’를 누르면 모든 학생 기록이 사라진다. 저장소에 아무것도 남지 않는다.
10. 3D가 안 되는 기기에서도 퀴즈를 끝까지 풀 수 있다.
11. 단답형은 정규화한 입력이 그 문항의 인정 답 목록 중 하나와 같을 때만 정답이다. (v1.1)
